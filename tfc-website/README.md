# The Filter Cafe (TFC) Website

Single-page responsive site built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure, navigation, calls and map links
- `styles.css` — visual design, responsive layout and animations
- `script.js` — menu data, category filters and interactions
- `assets/tfc-logo.jpg` — logo cropped from the supplied TFC menu PDF
- `assets/source-menu.jpg` — menu artwork used as a hero texture

## Run locally
Open `index.html` in a browser. For easier editing, VS Code + Live Server is recommended.

## Free deployment with GitHub Pages
1. Create a GitHub account at https://github.com/ if needed.
2. Create a public repository named `tfc-website`.
3. Upload `index.html`, `styles.css`, `script.js` and the `assets` folder.
4. Go to Settings → Pages.
5. Choose Deploy from a branch → `main` → `/ (root)` → Save.
6. GitHub will give you a free URL like `https://YOUR-USERNAME.github.io/tfc-website/`.

A custom `.com` domain normally costs money; the `github.io` address is free.

## Before launch
- Verify the phone numbers and prices against the latest menu.
- Replace the Google Maps search URL with the cafe's exact Google Maps share URL if you have it.
